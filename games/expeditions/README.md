# Expeditions

Three independent games built together, plus the optional assist plugin that reads all three services (which is why
they share one family for now):

- [The Silt Archive](docs/silt-archive.md): turn-based flooded-archive dungeon crawler (`silt-*` plugins, `contracts/silt-archive.ts`).
- [The Salt Ledger](docs/salt-ledger.md): party RPG (`salt-rpg-*` plugins, `contracts/salt-ledger.ts`).
- [Common Ground](docs/common-ground.md): household life simulation (`common-ground-*` plugins, `contracts/hearth-sim.ts`).
- [Expedition assist](docs/expedition-assist.md): optional, requested guidance for all three (`expedition-assist`).
