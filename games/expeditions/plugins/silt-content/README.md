# Silt Archive content

This data-only pack registers `silt/archive` as a `silt-archive`. It depends on `silt/game` for validation and interpretation. The three districts each contain three four-socket, dry-connected 9×9 templates. Geometry is selected by the game during district assembly; room purpose and encounters are independent of the template. See [the player guide](../../docs/silt-archive.md).
