# Silt Archive presentation

The presentation consumes the `Silt` service and mounts only when `Ui` is present. It uses an owned input context when available and a scoped click handler; all commands remain authoritative in `silt/game`. The visual layer uses existing pinned Assetrizz images served under `public/assetrizz`; see the asset provenance and license in that directory. See [the player guide](../../docs/silt-archive.md).
