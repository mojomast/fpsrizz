# Puzzles and cards

Grid push puzzles and the solitaire card scenarios, grouped because the optional assist plugin reads both services:

- [Stonewake](docs/stonewake.md): 3D push-puzzle chambers (`puzzle-*` plugins, `contracts/puzzle.ts`).
- [Portfolio puzzles](docs/portfolio-puzzles.md): Atelier and Watch scenarios on the same rules.
- [Portfolio cards](docs/portfolio-cards.md): Ash and Cloud on the shared piles engine (`portfolio-cards-*`, `contracts/portfolio-cards.ts`).
- [Assist](docs/portfolio-assist.md): optional hint button for `PushPuzzle` and `PortfolioCards` games (`portfolio-assist`).
